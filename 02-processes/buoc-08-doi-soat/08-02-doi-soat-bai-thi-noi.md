# 08-02. Đối soát bài thi Nói

Đối soát hồ sơ, kết quả và file ghi âm của phần thi Nói nhằm đảm bảo đầy đủ, chính xác trước khi quản lý hồ sơ nhận kết quả nhanh hoặc đóng gói gửi ÖSD.

{% columns %}
{% column %}
#### 📅 Thời điểm

Sau khi kết thúc phần thi Nói của từng buổi thi hoặc sau ngày thi cuối cùng (đối với kỳ thi diễn ra nhiều ngày).
{% endcolumn %}

{% column %}
#### 👤 Phụ trách

Exam Coordinator
{% endcolumn %}

{% column %}
#### ✅ Phê duyệt

Exam Director
{% endcolumn %}
{% endcolumns %}

***

### 👥 Vai trò & Trách nhiệm

| Vai trò | Trách nhiệm |
| --- | --- |
| Exam Coordinator | Đối soát hồ sơ, kết quả |
| Exam Director | Đối soát file ghi âm của phần thi Nói. Hỗ trợ xác minh và phê duyệt các trường hợp sai lệch hoặc phát sinh. |

### 📋 Chuẩn bị

- 📄 Hồ sơ phần thi Nói.
- 📄 Phiếu chấm phần thi Nói.
- 📄 Protokoll.
- 📄 Danh sách thí sinh.
- 💾 USB hoặc thiết bị lưu file ghi âm.
- 💻 Máy tính phục vụ đối soát và lưu trữ dữ liệu.

***

### ⚠️ Quy tắc thực hiện

{% hint style="danger" %}
### Đối soát theo từng phòng thi

- Thực hiện đối soát riêng cho từng phòng thi.
- Hoàn tất đối soát của một phòng trước khi chuyển sang phòng tiếp theo.
- Không trộn hồ sơ hoặc file ghi âm giữa các phòng thi.
{% endhint %}

{% hint style="danger" %}
### File ghi âm

- File ghi âm phải đầy đủ theo từng phòng thi.
- File ghi âm phải khớp với đúng thí sinh và đúng buổi thi.
- Không chỉnh sửa, đổi tên hoặc ghi đè file sau khi đã xác nhận hoàn tất.
{% endhint %}

{% hint style="danger" %}
### Kết quả phần thi Nói

- Chỉ sử dụng kết quả đã được giám khảo xác nhận.
- Mọi sai lệch phải được xác minh trước khi nhập vào hệ thống hoặc gửi ÖSD.
{% endhint %}

***

## 📖 Hướng dẫn thực hiện

{% stepper %}

{% step %}
### Tiếp nhận hồ sơ

- Tiếp nhận toàn bộ hồ sơ và file ghi âm từ từng phòng thi.
- Phân loại theo ngày thi, buổi thi và phòng thi.
{% endstep %}

{% step %}
### Đối soát kết quả

- Kiểm tra phiếu chấm phần thi Nói.
- Đối chiếu kết quả với Protokoll.
- Kiểm tra thông tin thí sinh, chữ ký và các biểu mẫu liên quan.
{% endstep %}

{% step %}
### Kiểm tra file ghi âm

- Kiểm tra đầy đủ số lượng file ghi âm.
- Đối chiếu file ghi âm với từng phòng thi.
- Đảm bảo file có thể mở và phát bình thường.
{% endstep %}

{% step %}
### Hoàn thiện hồ sơ

- Sắp xếp hồ sơ theo đúng thứ tự quy định.
- Đối với thí sinh đăng ký **nhận kết quả nhanh**, tách riêng hồ sơ để chuyển sang quy trình **03. Quản lý bài thi nhận kết quả nhanh**.
- Đối với thí sinh còn lịch thi ở ngày tiếp theo, bàn giao lại tờ bìa thông tin kèm hồ sơ cho giám thị để tiếp tục ghi nhận kết quả phần thi Nói.
{% endstep %}

{% step %}
### Hoàn tất đối soát

- Xác nhận toàn bộ hồ sơ phần thi Nói đã đầy đủ.
- Sắp xếp hồ sơ để chuyển sang bước xử lý tiếp theo.
{% endstep %}

{% endstepper %}

***

{% columns %}
{% column %}
{% hint style="info" %}
### Checklist hoàn thành

- [ ] Đã tiếp nhận đầy đủ hồ sơ.
- [ ] Đã đối soát kết quả phần thi Nói.
- [ ] Đã kiểm tra đầy đủ file ghi âm.
- [ ] Đã hoàn thiện hồ sơ của từng thí sinh.
- [ ] Không còn sai lệch chưa xử lý.
{% endhint %}
{% endcolumn %}

{% column %}
{% hint style="success" %}
### Hoàn thành khi

- Hồ sơ, kết quả và file ghi âm của phần thi Nói đã được đối soát đầy đủ.
- Sẵn sàng chuyển sang **03. Quản lý bài thi nhận kết quả nhanh** hoặc **04. Đóng gói & Lưu trữ bài thi**.
{% endhint %}
{% endcolumn %}
{% endcolumns %}

{% hint style="warning" %}
### Lưu ý

- Chỉ tách riêng hồ sơ đối với thí sinh đăng ký **nhận kết quả nhanh**.
- Đối với các thí sinh còn lịch thi ở ngày tiếp theo, tiếp tục sử dụng cùng tờ bìa thông tin để ghi nhận kết quả phần thi Nói ở các buổi thi tiếp theo.
- Chỉ chuyển hồ sơ sang bước tiếp theo sau khi đã hoàn tất toàn bộ nội dung đối soát.
{% endhint %}
